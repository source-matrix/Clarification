# تنظيم المستودع



يوضح هذا المستند توزيع مكونات Clarification ومسؤولية كل مجلد، حتى يستطيع المساهمون العثور على الشيفرة والأمثلة والاختبارات والتوثيق بسرعة.



## المكونات الرئيسية



- `crates/clarification-core`: نواة المعالجة المكتوبة بلغة Rust.
- 
- `crates/clarification-cli`: واجهة سطر الأوامر.
- 
- `bindings/`: الواجهات المساعدة للغات Python وGo وLua.
- 
- `examples/`: أمثلة تشغيل صغيرة قابلة للتجربة.
- 
- `tests/`: اختبارات النواة والواجهات.
- 
- `docs/`: أدلة الاستخدام، مرجع API، ومقارنة before/after.
- 


## مبدأ الإضافة



ينبغي أن تتضمن كل إضافة جديدة اختبارًا مناسبًا وتوثيقًا مختصرًا، وأن تحافظ على واجهة `Options` وتدرجها في النواة والواجهات المدعومة عند الحاجة.
