# Changelog

## 0.1.0 — 2026-08-20

Initial public release of Clarification. This release includes the Rust image-enhancement core, the cross-platform CLI, Python Pillow binding, Go CLI bridge, Lua CLI bridge, local-detail scoring, alpha preservation, examples, unit tests, and GitHub Actions validation.

The repository presentation now includes a focused README, architecture and before/after visuals, a dedicated `docs/guides` section, a reproducible asset builder, and a clearly separated layout for the core, language bindings, examples, tests, and documentation.

The portrait profile now supports tuned detail enhancement plus optional Lanczos scaling. The user-provided before/after pair and generated portrait outputs are documented under `docs/assets/before-after/`.
