# Changelog

## 0.1.0 — 2026-08-20

Initial public release of Clarification. This release includes the Rust image-enhancement core, the cross-platform CLI, Python Pillow binding, Go CLI bridge, Lua CLI bridge, local-detail scoring, alpha preservation, examples, unit tests, and GitHub Actions validation.

The repository presentation now includes a navigation-first README, architecture and before/after visuals, a dedicated `docs/guides` section, a reproducible asset builder, and a reference-oriented project layout inspired by [FLEX-GHOST/rusttgcalls](https://github.com/FLEX-GHOST/rusttgcalls).
